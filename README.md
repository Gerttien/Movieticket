# MovieTicketsQ1

## Question 1 - Movie Ticket Sales Report

Java console application to display the number of movie tickets sold for two different movies at a local cinema.

Features
- Display movie ticket sales report for 2024
- Use single and two-dimensional arrays
- Calculate total movie ticket sales for each movie
- Determine the top performing movie
Data Used
- Movies: Napoleon, Oppenheimer
- Months: JAN, FEB, MAR

| Movie | JAN | FEB | MAR |
| --- | --- | --- | --- |
| Napoleon | 3000 | 1500 | 1700 |
| Oppenheimer | 3500 | 1200 | 1600 |
 Expected Results
- Total movie ticket sales for Napoleon: 6200
- Total movie ticket sales for Oppenheimer: 6300
- Top performing movie: Oppenheimer

 Files
- Main.java
- IMovieTickets.java
- MovieTickets.java
- MovieTicketsTest.java
 How to Run
1. Open in IntelliJ IDEA
2. Run Main.java
3. The report will display in the console
